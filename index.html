PRODUCTION NOTES / LIMITES

Cette V1 est une console de répétition : sélection de titre, horloge de show, click réglable, décompte 2 mesures et appels de régie. Les appels et les clicks ne sont pas encore calés sur les mesures exactes des morceaux. Le lecteur Apple Music permet d'écouter la playlist, mais ce navigateur ne peut pas extraire les fichiers, créer les stems séparés ni synchroniser automatiquement les cues avec les morceaux protégés. Les timings exacts doivent être relevés sur les versions live/arrangements choisis.
